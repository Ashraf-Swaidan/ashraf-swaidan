# Styling Preferences

Design Philosophy:
The interface is built on a clean, light, and structured foundation with controlled moments of expressive visual impact.

The goal is not decoration, but directed emphasis through motion and typography.

---

Visual Direction:

Base Style:
- Light theme (off-white / soft neutral background)
- High contrast text (near-black primary)
- Minimal visual noise in default states
- Strong spacing and breathable layout

Typography:
- Bold uppercase for key statements and landing messages
- Clean sans-serif font for body content
- Typographic hierarchy is the primary design driver
- Large-scale text is used for emphasis and narrative impact

Color System:
- Limited palette
- One primary accent color for highlights and interactions
- Optional secondary accent used sparingly for transitions or emphasis
- Color is never decorative; it is functional emphasis only

Geometry & Visual Elements:
- Geometric shapes (circles, lines, grids) used as structural accents
- Subtle asymmetry is allowed for dynamism
- Visual elements support composition, not decoration

Motion System:
- Motion is intentional and meaning-driven
- Scroll-based transitions are a core interaction pattern
- Animations must be smooth, performant, and transform-based
- Motion is used to guide attention and communicate transformation (not decoration)
- Key pattern: fragmentation → alignment → convergence

Interaction Style:
- Scroll is the primary driver of experience
- Sections transition through state changes rather than page switches
- UI elements respond subtly to user movement (hover, scroll, focus)
- No constant animation loops

Visual Tone:
- Modern
- Editorial
- Slightly experimental in key moments
- Controlled, not chaotic

Performance Constraint:
- Visual richness must not compromise smooth interaction
- Motion complexity must remain GPU-friendly (transform/opacity based)
