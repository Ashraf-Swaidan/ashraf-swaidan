# SMARTAR

SMARTAR is an e-commerce Shopify store running on a **custom-made theme** — highly customizable merchandising, brand-owned layout, and storefront UX that does not read like a default Shopify skin.

The store is **AI-integrated**: intelligence is woven into the shopping and/or operator experience (product discovery, assistance, merchandising support — exact surfaces to be documented as captures land).

## Portfolio positioning

- **Slug:** `smartar`
- **Carousel order:** 3rd project (after Luxian and Papion System)
- **Hero labels (minimal pills):** `Shopify` · `AI Powered` — same visual language as Papion and Duwit case-study hero tags
- **Differentiator vs Luxian:** Luxian is owned full-stack commerce; SMARTAR is **Shopify-native** with a bespoke theme and AI layer on top of the Shopify ecosystem.
